COMO ATUALIZAR
1. Descompacte este ZIP.
2. No repositório do GitHub, envie TODO o conteúdo desta pasta para a raiz.
3. Confirme a substituição dos arquivos existentes.
4. Aguarde a publicação do GitHub Pages e faça Ctrl+F5 no navegador.

PADRÃO APLICADO
- Cor do município: MUN_QTD_EM_EXECUCAO (somente Gestão Municipal).
- Rótulo: NM_MUN + quantidade municipal em execução.
- Popup: Visão do território + Gestão Municipal + Outros Proponentes.
- Lista de entidades recolhível.
- WhatsApp para solicitar análise detalhada.
- Cache-busting nos arquivos principais da atualização.

VALIDAÇÃO DESTA BASE
